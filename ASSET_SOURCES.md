# Источники каркаса

Проверено 12 октября 2026. Каталог: https://museum.adygmath.ru/ru/ . Сведения о парке: https://museum.adygmath.ru/ru/about-math-park/ .

Первые три страницы заполнены по исходным страницам моделей; математические пояснения пересказаны, задания для наблюдения добавлены для учебного примера. Остальные восемь содержат только название, фотографию и каркас.

- Теорема Пифагора: https://museum.adygmath.ru/ru/models/pythagorean-theorem/
- Лист Мёбиуса: https://museum.adygmath.ru/ru/models/mobius-strip/
- Параболические шепталки: https://museum.adygmath.ru/ru/models/parabolic-whisperers/

Фотографии: сайт Математического парка, Республиканская естественно-математическая школа при АГУ. Автор конкретного снимка на просмотренной странице отдельно не указан. Каркас сохраняет ссылку на источник; отдельная лицензия на эти изображения здесь не заявляется.
