# Задание на два дня: 12 и 13 октября 2026

Участники выполняют одинаковый стартовый цикл. Восемь моделей распределены по две на участника: [таблица и критерии](docs/ASSIGNMENTS.md).

## День 1: открыть, понять, сохранить

- [ ] Зарегистрироваться на GitHub и создать личный репозиторий.
- [ ] Распаковать каркас, открыть главную и все три готовые модели.
- [ ] Найти в исходниках заголовок, изображение, ссылку и CSS-класс.
- [ ] Изменить одну надпись и один цвет; объяснить, какой файл изменён.
- [ ] Выполнить первый commit и push.
- [ ] Записать вопросы по исходному сайту.

## День 2: продолжить и проверить

- [ ] Начать первую из двух назначенных моделей из docs/ASSIGNMENTS.md.
- [ ] Добавить описание, математическую идею, вопрос или опыт и хотя бы одно локальное изображение.
- [ ] Обновить карточку и счётчики на главной.
- [ ] Проверить работу на широком и узком экране.
- [ ] Проверить menu → модель → главная, фотографии и отсутствие ошибок JavaScript.
- [ ] Сделать второй осмысленный commit и push.
- [ ] Подготовить показ результата к среде, 14 октября.

## Что показать руководителю

Ссылку на репозиторий, страницу в браузере и историю изменений. Каждый должен объяснить относительный путь к изображению, отличие HTML от CSS и смысл своего commit. Публикация через GitHub Pages — следующий шаг после локальной проверки.

## Приёмка каркаса студентом

- Главная показывает 11 моделей.
- Три готовые страницы содержат текст, фото, математическую идею и опыт.
- Восемь остальных открываются как отдельные заглушки.
- Страница работает с отключённым интернетом.
- Нет внешних зависимостей для открытия проекта.
