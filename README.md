# Математический парк — учебный каркас

Учебная копия структуры [museum.adygmath.ru](https://museum.adygmath.ru/ru/) для практики РЕМШ. Это самостоятельная реализация, а не точный клон кода исходного сайта.

## Быстрый запуск

Распакуйте весь архив и откройте `index.html` в Edge или Chrome. Сервер, Node.js и Python для просмотра не нужны. Фотографии находятся внутри проекта.

**Пошаговая инструкция:** откройте [START_HERE.html](START_HERE.html) в браузере или прочитайте [WINDOWS.md](WINDOWS.md).

**Распределение моделей:** [кто готовит какие страницы](docs/ASSIGNMENTS.md).

## Что готово

- Главная: 11 моделей, фильтр заполненных страниц и заглушек.
- Страница «О парке».
- Заполненные страницы: теорема Пифагора, лист Мёбиуса, параболические шепталки.
- Отдельные страницы-заглушки для остальных восьми моделей.
- Общая адаптивная стилизация, меню, увеличение фотографий, источники.

## Файлы

```text
mathpark-starter/
  index.html                 Главная и карточки моделей
  about.html                 О парке
  models/                    11 отдельных HTML-страниц
  assets/css/styles.css      Общие стили
  assets/js/main.js           Фильтр и просмотр фотографий
  assets/images/             Местные фотографии
  WINDOWS.md                 Инструкция для студентов
  TASKS.md                    Работа на два дня
  ASSET_SOURCES.md            Источники материалов
  docs/                      План и журнал решений
```

Редактировать можно обычные HTML-файлы. Контент не подгружается через `fetch`, поэтому локальный запуск через двойной щелчок работает.

## Как заполнить заглушку

1. Откройте первый из двух своих файлов в models/ по таблице docs/ASSIGNMENTS.md.
2. Откройте соответствующую страницу оригинала по ссылке на странице.
3. Изучите любой из трёх заполненных примеров.
4. Замените блок `.placeholder-notice` и список «Что добавить» своими секциями.
5. Сохраните локальные изображения в `assets/images/`; из модели путь начинается с `../assets/images/`.
6. На главной измените у карточки `data-status="draft"` на `ready`, подпись и статус; обновите счётчики.
7. Проверьте страницу, меню, фотографии и узкий экран.

## Источники и границы копии

Каталог, фотографии и проверяемые сведения взяты с исходного сайта; ссылки приведены в [ASSET_SOURCES.md](ASSET_SOURCES.md). Пояснения пересказаны для учебных страниц; вопросы и опыты добавлены в каркас.

В каркасе только русская версия. Формы, аналитика, служебные скрипты и отправка сообщений исходного сайта не скопированы. Все изображения хранятся локально.
