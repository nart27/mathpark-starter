## Предлагаемый темп

К среде, **14 октября**, показать первую страницу и её историю commit. К пятнице, **16 октября**, подготовить обе страницы. Сроки предложены для первой недели и могут быть скорректированы руководителем.

## Одинаковые критерии для каждой страницы

- [ ] Понятное описание экспоната своими словами.
- [ ] Правильное математическое объяснение; факты сверены с источником.
- [ ] Вопрос, опыт или наблюдение для посетителя.
- [ ] Локальная фотография и содержательный alt.
- [ ] Ссылка на исходную страницу модели.
- [ ] Убран блок заглушки; обновлены свои карточки на главной.
- [ ] Проверены меню, фотографии, мобильный вид и локальное открытие.
- [ ] Есть осмысленный commit и ссылка на результат.

## Как не мешать друг другу

Первые упражнения выполняются в личных GitHub-репозиториях. Для общего GitLab каждый работает в своей ветке и открывает merge request на две свои модели. Общие стили и JavaScript меняем после обсуждения. В главной меняем только свои карточки; итоговые счётчики согласуем при объединении.

Назначения зафиксированы локально. Для назначения карточек аккаунтам GitLab понадобятся GitLab-имена студентов; размещение задач пока ожидает доступа.
