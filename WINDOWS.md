# Windows: от каркаса до своей страницы

Практика РЕМШ: работа 12–13 октября 2026; в среду, 14 октября, показываем результаты. Все участники проходят одинаковые шаги. Источник: https://museum.adygmath.ru/ru/ .

В каркасе есть главная, «О парке» и 11 страниц моделей. Заполнены теорема Пифагора, лист Мёбиуса и параболические шепталки. Остальные восемь — заготовки.

## 1. Распакуйте и откройте сайт

1. Скачайте архив mathpark-starter.zip.
2. Нажмите на архив правой кнопкой → **Извлечь всё / Extract All**.
3. Выберите папку, например C:\Projects. Откройте извлечённую папку mathpark-starter.
4. Проверьте, что рядом лежат index.html, about.html, папки models и assets.
5. Включите расширения файлов: **Вид → Показать → Расширения имён файлов**. В Windows 10 переключатель находится на вкладке **Вид**.
6. Нажмите на index.html правой кнопкой → **Открыть с помощью → Microsoft Edge** или **Google Chrome**.
7. Откройте три готовые модели и любую заглушку. Перейдите назад на главную.
8. Отключите интернет и обновите страницу: тексты и фотографии должны остаться.

Открывайте страницу из распакованной папки, а не из окна ZIP. Сервер, Node.js и Python для просмотра не нужны.

## 2. Установите программы

1. Откройте https://code.visualstudio.com/download .
2. Выберите Windows **User Installer**, установите и откройте Visual Studio Code.
3. Откройте https://desktop.github.com/download/ .
4. Скачайте Windows-версию GitHub Desktop и установите её.

VS Code нужен для редактирования. GitHub Desktop — для сохранения изменений в Git и отправки на GitHub. В этом варианте командная строка не обязательна.

Справка: [VS Code для Windows](https://code.visualstudio.com/docs/setup/windows), [первый репозиторий в GitHub Desktop](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop).

## 3. Зарегистрируйтесь на GitHub

1. Откройте https://github.com/ → **Sign up**.
2. Выберите имя пользователя, зарегистрируйтесь и подтвердите электронную почту.
3. В GitHub Desktop нажмите **Sign in to GitHub.com**.
4. Завершите вход в браузере и вернитесь в Desktop.
5. Укажите имя и адрес для авторства commit, если программа предложит настройку.
6. Сохраните ссылку на свой профиль для руководителя.

Для начала достаточно бесплатного аккаунта. Общий GitLab polyaris/mathpark и ваш личный GitHub — разные проекты.

## 4. Создайте свой репозиторий

1. На GitHub откройте **+ → New repository**.
2. В **Owner** выберите свой аккаунт.
3. Имя: **mathpark-practice**.
4. Описание: **Учебная копия сайта Математического парка**.
5. Для дальнейшей публикации через GitHub Pages на бесплатном тарифе выберите **Public**.
6. Включите создание **README**, остальные шаблоны можно не добавлять.
7. Нажмите **Create repository**.
8. Сохраните ссылку вида https://github.com/ВАШЕ-ИМЯ/mathpark-practice .

Справка: [создание репозитория](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository).

## 5. Клонируйте репозиторий

1. В GitHub Desktop: **File → Clone repository**.
2. Выберите mathpark-practice на вкладке GitHub.com или вставьте адрес на вкладке **URL**.
3. Локальная папка, например: C:\Projects\mathpark-practice.
4. Нажмите **Clone**.
5. Откройте папку через **Repository → Show in Explorer**.

Клонируйте в отдельную новую папку, а не поверх уже распакованного каркаса.

Справка: [клонирование через Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop).

## 6. Перенесите каркас в рабочую папку

1. Откройте распакованную папку mathpark-starter.
2. Скопируйте **её содержимое**, а не внешнюю папку: index.html, about.html, models, assets, инструкции и остальные файлы.
3. Вставьте в C:\Projects\mathpark-practice.
4. Если предложено заменить README, это допустимо для вашего только что созданного пустого учебного репозитория: заменяется начальный README.
5. Не удаляйте скрытую папку .git.

Правильный путь:

~~~text
C:\Projects\mathpark-practice\index.html
~~~

Лишний уровень папки:

~~~text
C:\Projects\mathpark-practice\mathpark-starter\index.html
~~~

Откройте страницу именно из рабочей копии.

## 7. Выполните commit и push

1. В GitHub Desktop откройте **Changes**: должны появиться файлы каркаса.
2. Просмотрите изменения в index.html, styles.css и одном файле модели.
3. В **Summary** напишите: **Добавлен учебный каркас Математического парка**.
4. Нажмите **Commit to main**. Если ветка названа иначе, кнопка покажет её имя.
5. Нажмите **Push origin**.
6. Проверьте репозиторий в браузере: появились index.html и папки.

Commit сохраняет изменения в локальной истории. Push отправляет commit на GitHub. Сохранение файла в редакторе не заменяет эти действия.

## 8. Разберитесь в каркасе

1. В VS Code: **File → Open Folder** → C:\Projects\mathpark-practice.
2. Откройте index.html.
3. Нажмите **Ctrl+F** и найдите слово «Математику».
4. Найдите h1 — заголовок, a — ссылку, img — изображение.
5. Откройте assets\css\styles.css: в начале определены цвета.
6. Откройте models\pythagorean-theorem.html и найдите секцию с объяснением.

HTML задаёт содержание, CSS — оформление, JavaScript — фильтр и увеличение фотографий. Начните с конкретного блока, а не со всего кода сразу.

## 9. Сделайте первое изменение

1. Замените подпись «Каркас для собственной копии» своей понятной формулировкой.
2. Сохраните **Ctrl+S**.
3. В браузере нажмите **Ctrl+R** и проверьте результат.
4. В CSS найдите переменную **--green** и попробуйте другой близкий оттенок.
5. Посмотрите, какие элементы изменились. Верните согласованное оформление, если эксперимент хуже читается.
6. Сделайте commit с объяснением и **Push origin**.

## 10. Заполните заглушку

Каждому назначены две модели: откройте [таблицу распределения](docs/ASSIGNMENTS.md) и начните с первой своей страницы. Далее показан пример для додекаэдра; примените эти шаги к своему файлу.

1. Откройте, например, models\regular-dodecahedron.html.
2. Перейдите по ссылке **Страница оригинала**, изучите модель.
3. Найдите HTML-комментарий **ЗАДАНИЕ**.
4. Изучите структуру models\pythagorean-theorem.html как образец.
5. Замените блок placeholder-notice и список «Что добавить» своими секциями: описание, математическая идея, вопрос или опыт.
6. Сверьте факты с оригиналом. Объясните незнакомые понятия.
7. Добавьте файл, например assets\images\dodecahedron-detail.jpg.
8. В HTML модели укажите:

~~~html
<img src="../assets/images/dodecahedron-detail.jpg"
     alt="Модель додекаэдра: видны пятиугольные грани">
~~~

9. Сохраните ссылку на источник.
10. Вверху модели замените подпись **Заглушка · для работы** на **Заполненная страница**, а CSS-класс status-draft на status-ready.
11. В index.html найдите карточку этой модели:
    - замените data-status="draft" на data-status="ready";
    - измените описание;
    - замените status-draft на status-ready;
    - обновите подпись статуса.
12. В счётчиках главной замените 3 заполненные / 8 заглушек на 4 / 7.
13. Проверьте фильтр: заполненных страниц стало четыре.

Путь ../assets/... поднимается из папки models на один уровень, затем входит в assets. На главной используется assets/... без подъёма.

## 11. Проверьте результат

1. Откройте главную и три фильтра.
2. Проверьте «О парке», новую карточку, «Все модели» и «Следующая модель».
3. Нажмите фотографию и закройте просмотр кнопкой или **Esc**.
4. В Edge/Chrome нажмите **F12** и включите режим устройства кнопкой с телефоном; можно использовать **Ctrl+Shift+M**.
5. Выберите ширину около 360px: текст и кнопки не должны выходить за экран.
6. В **Console** проверьте отсутствие красных ошибок JavaScript.
7. Отключите интернет и ещё раз откройте страницы.
8. Создайте следующий commit и выполните push.

## 12. Опубликуйте через GitHub Pages

1. На GitHub откройте свой репозиторий → **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. В **Branch** выберите main и папку **/(root)**.
4. Нажмите **Save**.
5. Дождитесь публикации и откройте:

~~~text
https://ВАШЕ-ИМЯ.github.io/mathpark-practice/
~~~

6. Проверьте главную и страницу модели.

GitHub Free поддерживает этот способ для публичного репозитория. Сайт Pages доступен в интернете; в этот проект добавляем учебные материалы.

Справка: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [выбор ветки публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Публикация может занять несколько минут. При проблеме проверьте Actions и сообщение в Settings → Pages.

## 13. Подготовьте показ к среде

Покажите профиль, репозиторий, сайт и опубликованную ссылку, если публикация завершена. Откройте свою дополненную модель и историю commit. Объясните одно изменение, относительный путь к фото и различие HTML/CSS. Будьте готовы поменять текст прямо во время демонстрации.

## Частые затруднения

| Симптом | Что проверить |
| --- | --- |
| Вместо страницы текст | Файл должен быть .html, а не .html.txt; открывайте его браузером |
| Нет фотографий | Распакуйте весь архив; проверьте папку assets, имя файла и путь |
| Изменение не видно | Ctrl+S, Ctrl+R; проверьте, что открыта та же рабочая папка |
| На GitHub старый вариант | Нужны commit, затем Push origin |
| Фильтр не работает | Проверьте Console, файл assets/js/main.js и data-status |
| На Pages не открывается модель | Относительные ссылки и регистр имён файлов должны совпадать |
| Ошибка входа | Выполните вход в GitHub Desktop; пароль или токен не помещают в HTML |

## Переход к общему GitLab

Проект группы: https://gitlab.com/polyaris/mathpark . Личные репозитории GitHub не обновляют его автоматически. Руководитель согласует общую версию отдельно.

Для совместной работы клонируйте общий проект в отдельную папку. Дальше: ветка → изменение → commit/push → merge request → просмотр → объединение. Не меняйте origin своего личного репозитория на общий адрес. Назначения моделей указаны в docs/ASSIGNMENTS.md; общие изменения обсуждаются командой.
